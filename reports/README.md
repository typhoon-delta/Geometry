# Báo cáo của phòng thí nghiệm

Mỗi lần chạy `python -m lab chay` sinh một thư mục `reports/<ngày_giờ>/index.html` (không đưa lên git).
Mở nhanh báo cáo gần nhất (kèm ghi phản hồi "Hay"/"Chán"): `python -m lab bao-cao`.
Danh sách các lần chạy: `reports/index.html`. Xem hướng dẫn ở `lab/HUONG_DAN.md`.
